# Estudos ASP.NET Core

Repositório dedicado aos estudos e exercícios dos cursos de ASP.NET Core da formação [Full Stack Developer](https://desenvolvedor.io/formacao/full-stack-developer), da desenvolvedor.io.

Aqui serão organizados exemplos, anotações e projetos desenvolvidos ao longo da formação.

## Objetivo

Este repositório tem como finalidade centralizar os aprendizados relacionados à stack ASP.NET Core, cobrindo conceitos fundamentais e avançados de:

- ASP.NET Core MVC
- ASP.NET Core Web API
- REST APIs
- Entity Framework Core
- Arquitetura de aplicações
- Boas práticas e padrões de desenvolvimento

## Formação de referência

A formação Full Stack Developer da desenvolvedor.io abrange principais conteúdos de backend em ASP.NET Core e frontend em Angular, com foco em desenvolvimento profissional e aplicações reais.

## Estrutura

A estrutura do repositório pode evoluir conforme os estudos forem avançando, por exemplo:

- `src/` — projetos e aplicações desenvolvidas
- `docs/` — anotações e materiais de estudo
- `exercicios/` — pequenos exercícios e testes práticos
- `solutions/` — soluções de cursos ou desafios

## Como usar

1. Clone o repositório
2. Acesse a pasta do projeto desejado
3. Execute os exemplos ou projetos localmente
4. Registre anotações e melhorias no próprio repositório

## Observação

Este é um repositório pessoal de estudos, com foco em aprendizado prático e organização dos materiais da formação.
